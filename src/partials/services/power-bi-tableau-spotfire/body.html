How we engage

Four delivery patterns
that cover most asks.

Most BI engagements fall into one of these shapes. We size, scope, and price each one differently — and tell you which model fits before the SOW gets drafted.

Pattern 01

Greenfield dashboard delivery

New report or dashboard from scratch — requirements through semantic model, build, QA, and handover. Usually Fixed-Scope, 4-8 weeks.

Pattern 02

Report modernization / migration

Legacy reports (SSRS, Cognos, BO, older Tableau versions) re-platformed onto the client's current BI tool. Includes parity testing — the user shouldn't notice the change except in performance.

Pattern 03

Semantic-model and performance tuning

Existing reports that have grown slow or unmaintainable — we re-model, refactor measures, and rebuild data refresh. Typically T&M, 2-6 weeks.

Pattern 04

Embedded BI & white-label delivery

Power BI Embedded, Tableau JS API, or Spotfire JavaScript API integrations into client-facing portals. Designed for staffing-agency partners who white-label the work to a SaaS or services client.

Every BI engagement ships with a runbook — refresh schedules, on-call paths, and the documentation your support team needs after handover. The work outlasts our involvement.
